How It Works

Three steps. One answer.

01
INGEST
Paste raw logs, drop a file, or pull from your clipboard. NERVE accepts structured and unstructured output from Kubernetes, Redis, Postgres, Kafka, and any service that emits timestamped text.

02
ANALYZE
A three-model AI pipeline correlates signals across services. Nemotron 49B for primary analysis, Llama 8B for automatic failover, and a second Llama 8B pass to guarantee valid structured JSON output.
Nemotron 49B → Llama 8B fallback → JSON formatter
03
DIAGNOSE
Structured output in under 60 seconds: a reconstructed incident timeline, root cause hypotheses ranked by signal strength, concrete fix steps with real commands, and a severity score with blast-radius justification.

Signal Strength

Not all hypotheses are equal.

NERVE ranks every root cause candidate by the strength of its evidence trail — so you fix the right thing first, not the most recent thing you noticed.

HIGH Direct causal chain confirmed by multiple corroborating log lines. Fix this first.
MED Strong correlation across two or more services, limited direct causation evidence.
LOW Possible contributor, insufficient evidence. Background noise candidate — investigate last.

Redis OOM → API 503 Cascade
Redis memory exhaustion at 97.5% triggers cache thrashing, connection pool exhaustion, and full API gateway failure across all regions within 90 seconds.
Hover to reveal fix steps
Remediation
  • Promote replica-2 as primaryredis-cli REPLICAOF NO ONE
  • Increase memory limitCONFIG SET maxmemory 12gb
  • Switch eviction policyCONFIG SET maxmemory-policy volatile-lru
  • Throttle cache warm-up to prevent DB storm
  • Set alert threshold at 75% memory utilisation

Remediation

  • Add pool alert: trigger at 80% utilisation
